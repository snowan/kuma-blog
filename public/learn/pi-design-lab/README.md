# Pi Design Lab

中文交互式学习稿。直接打开 [index.html](index.html)：CSS、JavaScript、三个真实 Session 的结构投影全部内嵌，无需安装或联网运行。外部原文链接需要网络。

九节：全局关系、Agent 循环与 KV、稳定前缀、压缩、Session 树、可迁移性、Lane 与恢复、真实记录、迁移与复述。包含 10 组可播放/暂停/单步/重放的流程，变量实验、9 个预测检查、排序与 Teach-back。流程可以用 ← → 单步、空格播放暂停。

五张 SVG 图跟随控件与流程步骤重画：会话树（共同祖先 / 目标路径 / 离开的路径分色，可直接点选叶子）、前缀对照（“文本还相同吗”与“真正跳过了多少计算”两条独立的条，缓存不可达时它们会分开）、压缩前后的输入形状（同一 token 轴，含阈值线）、持久写入时间线（崩溃位置与效果未知的窗口）、以及整份 Session 的结构分布带（每行一格，按类型着色，可点击定位；495 行的样本也能一眼看出 compaction 与分叉的位置）。窄屏下图会横向滚动而不是缩到看不清。

默认 Control Room，可切换 Paper Journal / Mori Notebook。减少动态效果偏好下默认不自动播放，仍可手动单步。答案和笔记只保存到浏览器本课存储键 `kuma-pi-design-lab-v1`，支持 Markdown 导出。

- [研究与来源](sources.md)：固定版本、主张边界与三个样本的原始位置。
- [验证记录](validation.md)：实际运行的检查与未测范围。

这是互动学习材料。动画和预算为教学模拟；真实数据展示的是公开旧 v3 Session 结构，不能证明新 Harness 的恢复行为。
