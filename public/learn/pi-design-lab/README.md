# Pi Design Lab

中文交互式学习稿。直接打开 [index.html](index.html)：CSS、JavaScript、三个真实 Session 的结构投影全部内嵌，无需安装或联网运行。外部原文链接需要网络。

九节：全局关系、Agent 循环与 KV、稳定前缀、压缩、Session 树、可迁移性、Lane 与恢复、真实记录、迁移与复述。包含 10 组可播放/暂停/单步/重放的流程，变量实验、9 个预测检查、排序与 Teach-back。

默认 Control Room，可切换 Paper Journal / Mori Notebook。减少动态效果偏好下默认不自动播放，仍可手动单步。答案和笔记只保存到浏览器本课存储键 `kuma-pi-design-lab-v1`，支持 Markdown 导出。

- [研究与来源](sources.md)：固定版本、主张边界与三个样本的原始位置。
- [验证记录](validation.md)：实际运行的检查与未测范围。

这是互动学习材料。动画和预算为教学模拟；真实数据展示的是公开旧 v3 Session 结构，不能证明新 Harness 的恢复行为。
